# Hydra VPN — релизы

Здесь публикуются установочные файлы приложения **Hydra VPN** для Android. Исходный код хранится отдельно.

## Какой файл скачать

| Файл | Для каких телефонов |
|---|---|
| `hydra-client-X.Y.Z-arm64.apk` | почти все современные телефоны — **берите этот** |
| `hydra-client-X.Y.Z-arm32.apk` | старые телефоны (если arm64 не устанавливается) |
| `hydra-client-X.Y.Z-x86_64.apk` | эмуляторы и редкие планшеты |

Рядом с каждым APK лежит файл `.sha256` — контрольная сумма для проверки целостности.

## Обновления

Приложение само проверяет новые версии здесь (Настройки → «Проверить обновления») и предлагает установить.

## Предупреждение Play Защиты

Приложение распространяется не через Google Play, и Play Защита пока его «не знает». При установке она может:

- **предложить проверить приложение** («Отправить приложение на проверку?» / «Проверить приложение») — **соглашайтесь**: проверка занимает несколько секунд и помогает Google быстрее признать Hydra VPN безопасным для всех;
- **предупредить о неизвестном приложении** — нажмите «Подробнее» → «Всё равно установить».

Hydra VPN не читает SMS, уведомления и экран, не использует специальные возможности (accessibility) — только VPN и сеть.
